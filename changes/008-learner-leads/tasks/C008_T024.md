# C008_T024 · ■ on the live lead card stops the run

Found on the user's phone walk (2026-10-04) and reproduced in Chromium: tapping ■ while leading does nothing — the snapshot stays `lead.phase: "listening"`, the card stays live. Cause: `handleTogglePlay` in `src/ui/App.tsx` decides start-or-stop from `snapshot.transport.kind === "idle"` alone; a lead run never touches the transport, so ■ calls `session.start()`, which is a no-op while leading. Every earlier test stopped a lead run through `session.stop()`, never through the button.

**Files**
- Modify: `src/ui/App.tsx` (`handleTogglePlay`)
- Test: `tests/ui/scenarios/transport-card-lead.test.tsx` (extend)
