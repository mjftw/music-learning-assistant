# C008_T030 · A second microphone request never orphans the first: stop releases every stream (converge 2 W1)

Converge 2, W1 (`changes/008-learner-leads/record/converge-2.md`). The real listening adapter's `start()` (`src/listening/published/index.ts`) checks `graph !== null` only before it awaits `getUserMedia`, then sets `graph` without regard to one already there. Tap start → stop → start while the first permission request is still pending puts two requests in flight; whichever resolves second overwrites the other's graph, and the session's superseded branch (`if (result.ok) listening.stop()`, `src/practice/domain/session.ts` in `startLead()` and the tuner's equivalent in `enterTuner()`) tears down whichever graph is current — so one live microphone track can end up unreachable: ■ releases nothing and the orphan keeps publishing pitches. Requirements: listening.pitch-detection/REQ-001 — "WHEN listening is ended THE SYSTEM SHALL release the microphone within 200 ms so that the device no longer shows it in use" (S3: "… and no detected pitch is published afterwards"); practice.session/REQ-015 — ■ ends listening with the microphone released.

- Produces — the invariant, for every interleaving of `start()`, `stop()` and the resolution of pending `getUserMedia` requests:

  3. there is never a live track `teardown()` cannot reach.
  The controller's suggested shape (a two-way door — refine it if the code shows something simpler, and say so): the adapter keeps an epoch that `stop()` bumps; `start()` captures it before awaiting; when its stream arrives and the epoch has moved, it stops that stream's tracks itself, leaves any existing graph alone, and returns not-ok with an existing `reason` (no schema change — if the published `ListeningUnavailable` schema would have to change, STOP and report DECISION_NEEDED). When its stream arrives, the epoch has not moved, but a graph already exists (two starts with no stop between), it stops the arriving stream and returns ok. In the session, a superseded continuation calls `listening.stop()` only when nobody owns listening now (`listeningOwner === "none"`); if a newer request owns it, it leaves the microphone alone.
